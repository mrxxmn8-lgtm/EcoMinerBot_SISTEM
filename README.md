# EcoMinerBot_SISTEM
El EcoMinerBot es una plataforma robótica autónoma de ingeniería ambiental diseñada específicamente para mitigar el impacto ecológico de la actividad minera en la región de Tarma, Perú. Su objetivo principal es la remediación integral de pasivos mineros a través de un sistema multifuncional que purifica agua, filtra aire y restaura
